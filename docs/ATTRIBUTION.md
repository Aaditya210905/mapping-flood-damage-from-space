# Data attribution and licenses

The current application chooses the situation-report copilot AI component. Mapping uses change-detection rules with Sentinel observations, Copernicus DEM and historical OpenStreetMap. No external segmentation weights or satellite training datasets are used. EMSR927 remains evaluation-only.

Include these credits in every submission and generated report:

> Contains modified Copernicus Sentinel data 2026.

> Produced using Copernicus WorldDEM-30 © DLR e.V. 2010–2014 and © Airbus Defence and Space GmbH 2014–2018 provided under COPERNICUS by the European Union and ESA; all rights reserved.

> © OpenStreetMap contributors.

- Sentinel-1/2: [Copernicus Data Space](https://dataspace.copernicus.eu/), free, full and open policy. Original measurements are also served through the Microsoft public mirror; source IDs and storage URLs remain in run provenance.
- Copernicus DEM: [public distribution](https://registry.opendata.aws/copernicus-dem/), WorldDEM attribution above. The PROJ EGM2008 grid is used only for vertical datum conversion.
- OSM: [ODbL and copyright](https://www.openstreetmap.org/copyright), strictly historical geometry through [ohsome](https://api.ohsome.org/v1). Published modified OSM databases retain ODbL obligations; the code's MIT license does not relicense them.
- Copernicus EMSR927: [official activation](https://mapping.emergency.copernicus.eu/activations/EMSR927/). Credit **European Union, Copernicus Emergency Management Service data** when evaluation products are used. Store these separately and exclude them from prediction inputs.
- Leaflet 1.9.4: BSD-2-Clause, bundled license in `app/static/vendor/LEAFLET-LICENSE`.

The optional synthetic demonstration is generated by `app/demo.py` and labeled as test data. A fresh workspace contains no completed actual-data analysis. Original project brief ownership is separate from the authored application code.
