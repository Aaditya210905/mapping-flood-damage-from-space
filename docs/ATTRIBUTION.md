# Data attribution and licenses

The current application uses a user-supplied water-model adapter. Training-data downloaders and parsers are removed. The dataset distributions and six-product local case mentioned below describe the historical baseline; supply the citations for your own model through its metadata. EMSR927 remains evaluation-only.

Include these credits in every submission and generated report:

> Contains modified Copernicus Sentinel data 2026.

> Produced using Copernicus WorldDEM-30 © DLR e.V. 2010–2014 and © Airbus Defence and Space GmbH 2014–2018 provided under COPERNICUS by the European Union and ESA; all rights reserved.

> © OpenStreetMap contributors.

- Sentinel-1/2: [Copernicus Data Space](https://dataspace.copernicus.eu/), free, full and open policy. Original measurements are also served through the Microsoft public mirror; source IDs and storage URLs remain in run provenance.
- Copernicus DEM: [public distribution](https://registry.opendata.aws/copernicus-dem/), WorldDEM attribution above. The PROJ EGM2008 grid is used only for vertical datum conversion.
- OSM: [ODbL and copyright](https://www.openstreetmap.org/copyright), strictly historical geometry through [ohsome](https://api.ohsome.org/v1). Published modified OSM databases retain ODbL obligations; the code's MIT license does not relicense them.
- Kuro Siwo: Bountos et al. (2024), *Kuro Siwo: 33 billion m² under the water*, NeurIPS 37, 38105–38121. [Authors' repository](https://github.com/Orion-AI-Lab/KuroSiwo) links the [downloaded GRD distribution](https://huggingface.co/datasets/orion-ai-lab/Kuro-Siwo-Webdataset). Dataset card CC BY 4.0; repository code MIT. Both attribution and source links are retained.
- Sen1Floods11: Bonafilia, Tellman, Anderson and Issenberg (2020), *Sen1Floods11*, CVPR Workshops, 210–211. [Original repository](https://github.com/cloudtostreet/Sen1Floods11) links the public Google Cloud files downloaded here. The original repository has no license file; the supplied brief permits non-commercial educational use. No blanket code-license claim is made for the data.
- Copernicus EMSR927: [official activation](https://mapping.emergency.copernicus.eu/activations/EMSR927/). Credit **European Union, Copernicus Emergency Management Service data**. The six local products are evaluation-only and excluded from model/prediction inputs.
- Leaflet 1.9.4: BSD-2-Clause, bundled license in `app/static/vendor/LEAFLET-LICENSE`.

The optional synthetic demonstration is generated by `app/demo.py` and labeled as test data. The dashboard's default saved case uses actual downloaded sources. Original project brief ownership is separate from the authored application code.
