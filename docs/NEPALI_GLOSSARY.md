# Copilot English/Nepali terminology

These authored phrases preserve the distinction between a map estimate and a confirmed field observation. They support the existing controlled response templates. Independent native-speaker review has not been completed; this is a review handout, not a sign-off.

| English meaning | Nepali wording | Intended interpretation |
| --- | --- | --- |
| Situation report | बाढी स्थिति प्रतिवेदन | Briefing produced from the selected analysis |
| Potential new inundation | सम्भावित नयाँ डुबान | Detected candidate water; not field-confirmed inundation |
| Possible surface/debris change | सम्भावित माटो/ढुंगा वा भूआवरण परिवर्तन | Candidate change; not a confirmed debris flow |
| Potential infrastructure exposure | पूर्वाधारमा सम्भावित प्रभाव | Intersection with mapped changes |
| Damage is unconfirmed | क्षति पुष्टि भएको छैन | Preserve uncertainty; do not translate as destroyed |
| Modeled settlement connectivity | मोडेल अनुसार बस्तीको सडक सम्पर्क | Network calculation under stated assumptions |
| Modeled loss of road access | मोडेल अनुसार सडक सम्पर्क गुमेको | Simulated route loss; actual closure is unverified |
| Uncertain access | सडक सम्पर्क अनिश्चित | Incomplete or unobserved route evidence |
| Unassessed | मूल्याङ्कन भएको छैन | No supported assessment; not a zero count |
| Historical OSM snapshot | ऐतिहासिक OSM को मिति | A map snapshot from before the event |
| Unavailable | उपलब्ध छैन | Missing evidence stays missing |
| Synthetic demonstration | कृत्रिम प्रदर्शन | Generated software-demo inputs, not real event findings |
| Important limitations | सीमाहरू | Retain qualifications when shortening a report |

Names, feature IDs, scene IDs and acquisition dates retain the saved source spelling. Numerical values are resolved in Python; translation cannot recalculate them. Canonical units remain in the JSON evidence: km² is displayed as वर्ग कि.मि., km as कि.मि., m as मिटर and degrees as डिग्री. A footprint fraction stays a fraction; it is not silently converted into a percentage.

Review priorities: disaster-response readability, the term for surface/debris change, clarity of assumed road disruption, preservation of missing-data statements and appropriate formality. Record reviewer feedback and corrections before describing the Nepali language as externally reviewed.
